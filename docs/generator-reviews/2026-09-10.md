## Proposed edits

Each is a diff against the file named; none is applied.

### 1. T6, in "Honesty rules for this report"

**Rationale (observed).** The survey's own cost section is its differentiated product, and it was quoting a number the venue does not charge. Two contradictions on the same day is the T6 threshold.

Old:

```
- If the data for a field is missing, it reads "no data". Do not fill gaps with plausible-sounding estimates, and do not interpolate from an adjacent benchmark.
```

New:

```
- If the data for a field is missing, it reads "no data". Do not fill gaps with plausible-sounding estimates, and do not interpolate from an adjacent benchmark.
- **A catalog price is one endpoint's price, and it is Measured only for a pinned run.** On a venue that routes, the listing's price is a floor: two runs on 2026-09-06 were billed at 2x and 1.6x list because the router chose a different endpoint. Quote the billed figure from the run's status record for any run that was not pinned, and never present a catalog computation as what a run cost.
```

Old:

```
The limitations note is the point of the section.
```

New:

```
**A vendor that withdraws a free listing while keeping the paid one is a repricing, not a delisting**, and the churn line says so with both prices. minimax/minimax-m3:free left OpenRouter between 2026-09-01 and 2026-09-07 while minimax/minimax-m3 stayed at $0.30 and $1.20 per million; a reader who reads that as "the model is gone" draws the wrong conclusion about what to plan for.

The limitations note is the point of the section.
```
