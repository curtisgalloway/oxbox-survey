# GLM-5.3 Flash baseline on the scanner fix: passes all three gates, and named the self-scan hit before the scorer did

**What happened** — `oxbox-secret-scanner-fix` (39,467 B, `ox` at `6072d56`, `--mode
diff`) put to `z-ai/glm-5.3-flash`, the paid route of the revealed Ox Alpha and
rank 2 of the current manifest, never run until now. Clean apply, 8 of 8, zero
self-hits, in contract. Its explanation's fourth bullet reads: "Guard against a
new self-scan hit (`max_tokens = DEFAULT_MAX_TOKENS` in ox's own source) with a
case-sensitive negative lookahead that refuses values shaped like
SCREAMING_SNAKE constant references." That is the exact line Sonnet 5's patch
tripped on, found by reading the payload rather than by being told.

## Evidence

Run `logs/2026-09-03T03-11-19Z`, `context_bytes` 39467, `finish_reason` stop,
`truncated` false. `corpora/scorers/secret_scanner_fix.py`:

```
gate 1  APPLY   PASS  git apply --check clean
gate 2  SCAN    8 of 8 verdicts hold
gate 3  SELF    PASS  zero hits over ox at the pin and as patched
scope   in contract: nothing outside SECRET_PATTERNS changed
RESULT  PASS
```

The pattern, two adjacent string literals:

```
(?i)\b[\w.\-]*(api[_\-]?key|secret|password|token)[\w\-]*["']?\s*[:=]\s*
["']?(?-i:(?![A-Z][A-Z0-9]*(?:_[A-Z0-9]+)+\b))[^\s"']{16,}
```

Two things the gates do not measure. The identifier half now admits *any*
word characters after the keyword, so `max_tokens` is matched as an identifier
and only the value-side guard keeps `max_tokens = DEFAULT_MAX_TOKENS` clean —
a `(?-i:...)` scoped case-sensitivity flip with a lookahead refusing
`UPPER_SNAKE` values. It works on `ox` at the pin; a real secret written as a
constant reference would be skipped by design, which the model says out loud.
And the output has a stray line reading `diff` above the fenced block, a small
contract miss that the extractor tolerated.

Completion 20,635 tokens, 20,163 of them reasoning; 9 minutes wall clock.
Computed cost $0.0059.

## So what

Rank 2 of the manifest has been carrying a "nobody has run the paid route"
caveat since edition 1. It now has a run, and on this fixture it matches the two
clean frontier passes for a hundredth of Sonnet's computed cost. The unprompted
self-scan check is the single most interesting thing any model did on this
fixture tonight: it is the requirement the answer key had to grow a third gate to
express, and this model derived it from the prompt's one sentence about ox
reading its own source.

This is a baseline observation and carries no marker. The same model is a
manifest candidate under a different role; a candidate run on a human-verified
fixture is what would move its entry.
