| QW1 | `read_probe` misclassifies a directory as blocked when `stat` is denied but `open` and `listdir` are allowed | **invention** | The standing one: Sonnet's S1, GPT's P5, Fable's 1, Opus 5's 2. `jail.sb` grants `file-read*` per path, data and metadata together, and bubblewrap does not bind the home paths in at all, so no path answers `open` and refuses `stat`. |
| QW2 | `tcp_connect` treats a connection timeout as blocked, so a jail that permits TCP reports PASS when `1.1.1.1` is unreachable or slow | **real** | L1, confirmed at this pin: `jailtest.py:52-54` scores any raise as containment, and a `socket.timeout` from a dead route is a raise. | QW3 | `dns_lookup` has no timeout and hangs if DNS is allowed but the resolver is unresponsive | **invention** | The precondition is a jail that permits DNS. Seatbelt denies all network and the mach lookup to mDNSResponder; bubblewrap unshares the network namespace. `getaddrinfo` fails fast on both, so the hang needs a state this tree cannot produce. |
| QW4 | Only `AF_INET` is probed, so a jail that blocks IPv4 and allows IPv6 passes | **invention** | A coverage note, and the scenario needs a backend that filters by address family. Neither does: seatbelt's `network*` deny and bubblewrap's absent stack cover every family. |
| QW5 | UNCERTAIN: `env_canary` tests truthiness, so an inherited empty-string key is not reported | **invention** | Opus 5's 8 and Gemini 3.8 Flash's 2. The launcher builds the jail environment from scratch (`oxbox:346-358`) and `--clearenv` on Linux; no parent variable crosses, empty or not. |
| QW6 | UNCERTAIN: the canary list is hardcoded and can drift when a venue is added | **invention** | Stated as a future change ("oxbox later adds `ANTHROPIC_API_KEY`"). At this pin the launcher injects no credential, so nothing escapes the list. |
| QW7 | UNCERTAIN: the root skip is not applied to the stat oracle, so as root with `EXISTING[0]` = `/etc/shadow` and stat allowed, the oracle FAILs while the read probe was skipped | **real** | G1, at this pin, on Linux: in a container with an empty `/root` and no `.env`, `EXISTING` is `["/etc/shadow"]` (`oxbox:93-107` appends it last, `oxbox:343` filters by existence), the read probe skips at uid 0 (`jailtest.py:128`), and `os.stat` on a path inside the ro-bound `/etc` succeeds (`oxbox:190-197`), so the oracle reports FAIL. | QW9 | UNCERTAIN: empty `HOME` makes the work-dir probes use a relative path | **invention** | Sonnet's hedge on 2026-09-02, Opus 5's 2. `oxbox:349` sets `HOME` to the work dir on both backends. |
