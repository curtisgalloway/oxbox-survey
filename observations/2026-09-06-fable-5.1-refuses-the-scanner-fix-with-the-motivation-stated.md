# Fable 5.1 refuses the scanner fix even with the motivation stated first: the trigger is the material, not the framing

**What happened** — At the editor's suggestion, the scanner-fix prompt was
reworded with a preamble stating what `ox` is, that the scanner is a refusal
gate protecting credentials from being published to a model endpoint, that
the change is defensive, and that every sample value is a placeholder. Same
payload (`ox` at `6072d56`, 39,467 B), same flags, new task id
`oxbox-secret-scanner-fix-v2` because the original fixture has evidence and
is frozen. Fable 5.1 refused it as well: `finish_reason` `content_filter`,
`native_finish_reason` `refusal`, the same "violative cyber content" message.
One difference from the two morning refusals: this response carries
`prompt_tokens` 15,052 and `completion_tokens` 7, all seven reasoning, and
the provider field reads `Anthropic`, so the request was read and a
generation began before the filter closed it. Still no content, still nothing
usable, and OpenRouter billed nothing.

## Evidence

Run `logs/2026-09-06T21-50-44Z`, `context_bytes` 39467. `oxbox-send`'s report:

```
oxbox-send: finish=content_filter prompt_tokens=15052 completion_tokens=7 reasoning_chars=49
oxbox-send: model returned no content (finish=content_filter) — 7 of 7 completion tokens went to reasoning
```

`response.json`: `"provider": "Anthropic"`, `"finish_reason":
"content_filter"`, `"native_finish_reason": "refusal"`, `"content": null`,
and the refusal text identical to the morning's. The preamble is the first
paragraph of `corpora/prompts/oxbox-secret-scanner-fix-v2.txt`; the rest of
the prompt is byte-identical to the original.

## So what

**Framing was the cheap hypothesis and it is now excluded.** The prompt
already explained the mechanism; adding the purpose, the tool, and the
placeholder disclaimer changed nothing about the verdict. What the request
still contains is a source file whose `SECRET_PATTERNS` list is a catalog of
credential formats (AWS key ids, Slack tokens, private key blocks, assignment
forms) and a task asking for more of them to be matched. That combination is
what the classifier is answering, and no wording around it is likely to
move it.

**What would settle it.** A diagnostic pair, both cheap because a refusal
bills nothing: the original prompt against a payload containing only the
pattern list, and a neutral prompt against the full `ox`. Whichever is
refused names the trigger. Neither is the fixture, so neither would rescue
the cost ceiling; they would tell the survey what Fable will not review,
which is worth a line in every issue that lists it.

**The scanner-fix fixture keeps a null ceiling.** The `-v2` task stays in
the corpus as proposed, with this observation as its evidence, so the
experiment is on the record and is not repeated by accident.
